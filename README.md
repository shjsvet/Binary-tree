# Бинарное дерево поиска (BST) на Python

Этот проект представляет собой реализацию классического бинарного дерева поиска (Binary Search Tree) на языке Python. Дерево поддерживает вставку, поиск и удаление элементов, а также имеет удобную текстовую визуализацию структуры.

## Структура проекта

Код состоит из двух основных классов:

*   **`Trinode`** — класс, описывающий узел дерева. Содержит значение (`value`) и ссылки на левого (`left`) и правого (`right`) потомков.
*   **`Tree`** — основной класс, управляющий деревом. Хранит корень (`root`) и реализует всю логику работы.

## Основные методы

### 1. Вставка (`insert`)
Добавляет новое значение в дерево. Если значение уже существует, дерево не меняется (дубликаты игнорируются).
*   **Логика:** Если значение меньше текущего узла — идем влево, если больше — вправо. Рекурсивный спуск до свободного места.

### 2. Поиск (`find`)
Находит узел с заданным значением и возвращает его (объект `Trinode`).
*   **Логика:** Аналогична вставке, но если значение найдено, возвращается сам узел. Если дерево пройдено до конца и значение не найдено — возвращается `None`.

### 3. Удаление (`eliminating`)
Удаляет узел с заданным значением из дерева.
*   **Сложные случаи:**
    *   *Узел без детей:* просто удаляется (заменяется на `None`).
    *   *Узел с одним ребенком:* ребенок встает на место удаленного узла.
    *   *Узел с двумя детьми:* находится минимальный элемент в правом поддереве (он называется преемником), его значение копируется в удаляемый узел, а затем преемник удаляется из правого поддерева.

### 4. Печать (`print_tree`)
Выводит все значения дерева в консоль.
*   **Особенность:** Используется обратный обход (сначала левое поддерево, потом правое, потом корень). Из-за этого числа выводятся не по порядку, а в порядке, зависящем от структуры дерева (пост-ордерный обход).

### 5. Отрисовка (`draw_simple`)
Выводит структуру дерева в консоль в виде текстовой схемы.
*   **Как это работает:** Используется рекурсивный обход. Сначала рисуется правое поддерево (чтобы оно оказалось сверху), затем текущий узел, затем левое поддерево. Для отступов используются символы `|`, `--`, `L`.
*   **Особенность:** Метод использует простые ASCII-символы, поэтому он гарантированно отображается корректно в любой консоли (Windows, Linux, macOS) без настройки шрифтов.
